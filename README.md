# TaskFlow CLI

Небольшое CLI-приложение на Node.js для хранения списка задач в `tasks.json`. Сторонние зависимости не используются.

## Требования

- Node.js 18 или новее

## Запуск

Перейдите в каталог проекта и запускайте команды через npm:

```bash
npm start -- --help
npm start -- add "Подготовить отчёт"
npm start -- list
```

Либо напрямую через Node.js:

```bash
node src/cli.js add "Подготовить отчёт"
node src/cli.js list
```

## Команды

- `add "Название задачи"` — добавить задачу.
- `list` — вывести все задачи.
- `--help` — показать справку.

Задачи хранятся в `tasks.json` рядом с `package.json`.
